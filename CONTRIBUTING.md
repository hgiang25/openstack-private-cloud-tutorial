# Contributing

Thank you for your interest in contributing to this project.

Although this repository primarily serves as a personal infrastructure portfolio, contributions that improve documentation, diagrams, deployment guidance, or troubleshooting references are welcome.

## Ways to Contribute

You can contribute by:

- Improving documentation
- Fixing grammatical errors
- Updating OpenStack deployment instructions
- Improving architecture diagrams
- Suggesting best practices
- Reporting issues
- Sharing deployment experiences

---

## Pull Requests

Please ensure that your Pull Request:

- Focuses on a single topic.
- Includes clear descriptions.
- Does not introduce unrelated changes.
- Updates documentation if necessary.

---

## Documentation Style

Please follow these guidelines:

- Use Markdown.
- Keep language professional.
- Prefer diagrams over long paragraphs.
- Include references where appropriate.
- Keep command examples tested.

---

## Branch Naming

Recommended naming convention:

feature/<topic>

bugfix/<topic>

docs/<topic>

example:

feature/add-ceph-backend

docs/update-network-design

---

## Commit Messages

Recommended format:

docs: update deployment guide

fix: correct neutron configuration

feat: add monitoring documentation

refactor: improve architecture diagrams

---

Thank you for helping improve this repository.
