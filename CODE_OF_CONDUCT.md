# Code of Conduct

## Our Commitment

This repository aims to provide a welcoming, respectful, and professional environment for everyone interested in cloud computing, virtualization, Linux administration, and DevOps.

All participants are expected to contribute constructively and respectfully.

---

# Expected Behavior

Contributors are encouraged to:

- Be respectful and professional.
- Share knowledge openly.
- Provide constructive feedback.
- Help improve documentation.
- Discuss technical topics objectively.
- Respect differing opinions and experiences.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or personal attacks
- Offensive language
- Discrimination of any kind
- Spam or self-promotion unrelated to the project
- Publishing confidential information
- Intentional misinformation
- Disruptive or hostile discussions

---

# Documentation Standards

When contributing documentation:

- Use clear technical language.
- Keep explanations concise.
- Verify command examples.
- Prefer official references when possible.
- Clearly distinguish facts from personal recommendations.

---

# Reporting Issues

If you experience inappropriate behavior, please:

1. Open a private discussion with the repository owner.
2. Provide sufficient context.
3. Include screenshots if appropriate.

All reports will be handled respectfully and confidentially.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation contributions
- Community interactions related to this repository

---

# Enforcement

Project maintainers reserve the right to:

- Edit documentation for clarity.
- Close inappropriate issues.
- Reject pull requests that do not align with project goals.
- Remove spam or abusive content.
- Restrict participation if necessary.
